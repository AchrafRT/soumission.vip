RENOVATION PATCH CHANNEL
========================
Future renovation packages can place Python patch source into Renovation\patch.txt or drop .txt scripts into Renovation\inbox\.
Press "Refresh / Apply Patch" in the owner window to execute them.
Successful scripts move into Renovation\patched\. Failed scripts move into Renovation\failed\.
A pre-patch snapshot is stored in Renovation\snapshots\.

The older Patch\ channel is also supported, so both workflows remain compatible.
